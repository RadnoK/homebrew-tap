# RadnoK Homebrew Tap

Homebrew tap dla moich aplikacji macOS.

## Instalacja

```bash
brew tap RadnoK/tap
```

## Dostępne pakiety

### ZTE Menu

Aplikacja w pasku menu pokazująca status modemu ZTE U50 5G — bateria, sygnał,
typ sieci, operator i statystyki transferu.

```bash
brew install --cask zte-menu
```

Repozytorium: [RadnoK/zte-menu](https://github.com/RadnoK/zte-menu)
